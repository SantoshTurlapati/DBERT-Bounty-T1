
# Sales Data Analysis

A beginner-friendly Python project using Pandas to
analyze sales data and generate summary statistics.

## Features

- Calculate total sales
- Calculate average sales
- Find highest sales
- Find lowest sales
- Count total records
- Validate input data
- Automated tests using Pytest

## Technologies Used

- Python
- Pandas
- Pytest

## Installation

Install the required packages:

pip install -r requirements.txt

## Run the Project

python src/main.py

## Run Tests

python -m pytest tests/ -v
